# Changelog

## v0.1.0 · 5 November 2026
- An interview turns an owner's rules into typed checks, plus an AI-judge rubric for the one rule code can't decide; every check is proven on her example weeks first.
- A read-only rota assistant and a website chat, both gated by those rules; only the owner's Approve writes a rota, and the chat tells customers it's an AI.
- Evidence page per run, the gate as an MCP server, and PostHog traces that carry structure only by default.
- Stress test in CI: 10,000 random rota changes, every rule-breaking draft stopped, no good one blocked.
- Demo replays offline from recorded runs, no API key needed.
