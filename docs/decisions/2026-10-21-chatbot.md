# The chatbot second act

**Date:** 21 Oct 2026

The same gate, pointed at a different kind of agent: a website chatbot that talks to customers with nobody checking it first.

## What we decided

- **Same owner, same interview.** Gráinne's notes gain a "website chatbot" section with four rules, each with a story of what went wrong. The interview is the same code, told it's setting up chatbot rules.
- **Claude reads, code decides.** Code can't reliably read free text, so each draft reply first goes to Claude, which lists only what the reply promises (an item safe for an allergy, a discount, a booking). Gráinne's checks, written by Claude at setup and run in the sandbox, decide on those promises against her allergen sheet and opening hours. Same reply, same promises, same answer.
- **Three code rules, one judged:** allergens (only what her allergen sheet confirms), no discounts, bookings up to 8 between 7am and 7pm. "Sound like us" goes to the AI judge, and only once the code checks pass.
- **No human approves each message.** Customers can't wait. A passing reply is delivered by the gate's own code (`deliver()` in `store.ts`), which re-runs the code checks before writing. A stopped draft goes back to the bot with only what broke. After three stopped drafts the customer gets a fixed holding line and the question is held for Gráinne. The bot itself still has no way to send anything.
- **The bot reads the public menu, never her allergen sheet**, and is not given her rules.
- **The bot is set up like a literal FAQ bot** (answers from the menu page as written, handles questions itself, confirms bookings). That is how the incident in her notes happened.

## What we learned

Claude would not call the banana bread nut-free even when set up as a literal menu bot: it told the customer to check with staff every time. The allergen check stays as the safety net, and the demo's catch is the booking (the bot books 10 at 7.30pm unprompted). That turned into a point, not a problem: we tried to make Claude say it and it wouldn't. Your vendor's bot may not be Claude, and the gate doesn't care which model it is.

## Results at setup

Allergens 8/8, discounts 8/8, bookings 8/8 (her six replies plus two edge cases Claude wrote), tone 6/6. A full conversation costs about a fifth of a cent.
